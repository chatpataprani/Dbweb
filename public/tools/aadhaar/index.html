Local Aadhaar format check

Checks the 12-digit format and Verhoeff checksum directly in this browser.

Spaces are optional. The number is not sent to a server.

Important: A valid checksum does not confirm that an Aadhaar number exists, is active, or belongs to any person. This tool does not connect to UIDAI or any external service.
