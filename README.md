## What's Dbweb?

Dbweb brings useful browser tools together—because opening 17 tabs for one task is not the move.

| Space | What you can do |
| --- | --- |
| **Photo Studio** | Edit images, apply filters, create collages and add text. |
| **Background Remover** | Cut out backgrounds and export transparent PNGs. |
| **Developer tools** | Work with JSON, Base64, regex, URLs and Markdown. |
| **Image & file tools** | Compress, compare and inspect files and metadata. |
| **Validators & utilities** | Use supported Aadhaar, PAN, GST, vehicle, IFSC, QR and date tools. |
| **Social tools** | Access supported public-media workflows (provider rules apply). |
| **Workspace** | Manage plans, history, redeem codes, settings and account features. |
| **Admin** | Access management features with authorized admin permissions. |

> Feature availability can depend on browser support, configuration and third-party providers. The live site is the source of truth for the current lineup.

## Get started

**Prerequisites:** Node.js and npm.

```bash
git clone https://github.com/chatpataprani/Dbweb.git
cd Dbweb
npm install
```

Create your local environment file:

```bash
cp .env.example .env.local
```

Add the environment values required by your setup. Keep secrets private—never commit tokens, passwords, keys or real credentials.

Start development:

```bash
npm run dev
```

Open **http://localhost:3000**.

Build for production:

```bash
npm run build
npm start
```

## Deploy

Dbweb works with Next.js-compatible hosting.

1. Import this repository into your hosting platform.
2. Configure required environment variables securely.
3. Build using `npm run build`.
4. Deploy and test the routes and features you use.

Environment changes may require a fresh deployment. Yep, the classic.

## Important

- Background removal may use on-device processing or a configured online fallback.
- Browser, hardware and provider support can affect functionality.
- Keep server-side secrets on the server.
- Use Dbweb lawfully; respect privacy, consent and third-party terms.
- Don't use tools to stalk, harass, impersonate, defraud or harm anyone.
